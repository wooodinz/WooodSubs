# WooodSubs — wooodestic subtitles

Десктоп-приложение для Windows для создания, редактирования и стилизации субтитров **WhisperX → DaVinci Resolve (Text+)** с ретро-аппаратным интерфейсом, живым предпросмотром 16:9 и 3 темами (**Тёмная**, **Светлая**, **WIN** Windows 11).

## Возможности
- **Источники аудио/видео:** активный таймлайн DaVinci Resolve, локальный файл или ссылка (YouTube и др. через `yt-dlp`).
- **WhisperX с выравниванием по словам:** выбор модели, языка, размера пакета, диаризация спикеров.
- **Встроенный редактор субтитров:**
  - Живой предпросмотр кадра 16:9 со всеми анимациями, фактурой и тенями, как в DaVinci Resolve (поддержка стандартного `Text+`, дистресс-пресетов и `css_melting_text`).
  - Инструмент **Орфография** (выборочное удаление/сохранение знаков препинания и регистр слов с откатом).
  - Разбивка по словам/строкам, режим накопления (`reveal`), длительность удержания и **ИИ-маска «За персонажем»**.
  - Прямой экспорт `Text+` на таймлайн DaVinci Resolve.
- **100% офлайн-интерфейс** без внешних CDN + автосохранение последних выбранных параметров.

## Скачать готовую версию
Перейдите в раздел **Releases** справа на странице репозитория и скачайте **`WooodSubs.exe`**.

## Запуск из исходников
Дважды кликните `run.bat` или выполните:
```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python app.py
```

## Сборка `.exe`
Запустите `build_exe.bat` — готовый файл появится по пути `dist\WooodSubs.exe`.
При пуше тега вида `v1.0.0` GitHub Actions (`.github/workflows/release.yml`) автоматически соберёт `WooodSubs.exe` и опубликует релиз.
